Implementasi Cloud Computing

Arsitektur Komputasi Awan BetulinAja

Sesuai silabus mata kuliah Komputasi Awan UNIPI, aplikasi ini menerapkan Decoupled Modern Cloud Architecture yang memisahkan static edge delivery, REST API processing, dan cloud data persistence.

Layer 1: Edge Frontend
Vercel Global Edge CDN

Frontend HTML/CSS/JS di-deploy secara statis di Vercel Root Directory tanpa overhead runtime PHP.

  • Penyajian instan < 50ms dari server CDN terdekat.
  • Clean URL routing melalui vercel.json.
  • CORS Preflight terhubung aman ke backend REST API.
Layer 2: Backend API
Laravel 12 Cloud API

Backend container menjalankan REST API berstandar JSON API dengan keamanan Laravel Sanctum.

  • Autentikasi role Pelanggan, Mitra & Administrator.
  • Automated lifecycle dispatching dan status updates.
  • 21 automated test suites (89 assertions) lulus 100%.
Layer 3: Cloud Database
Persistent Cloud Database

Basis data cloud persisten (PostgreSQL / MySQL) dengan automated migration dan relasi referensial penuh.

  • Tabel: users, services, orders, order_status_logs.
  • Foreign key integrity & automated timestamps.
  • Backup database mandiri tersedia di database/betulinaja_backup.sql.

Siap Menggunakan Layanan BetulinAja?
